The wire

A socket delivers a stream of bytes with no message boundaries. Each message is a 4-byte length followed by that many bytes of JSON. This unit is a frame. MAX_FRAME is the largest request that the broker accepts.

setting value
length prefix 4 bytes, big-endian
MAX_FRAME 1,000,000 bytes

The broker checks the length before it reads the body, and raises ValueError for a longer request. A client therefore cannot make the broker allocate a large buffer. A client that disconnects raises EOFError in the reader.

a, b = socket.socketpair()
_send_json(a, {'op': 'send', 'msg': 'hello'})
test_eq(_recv_json(b), {'op': 'send', 'msg': 'hello'})
a.sendall((MAX_FRAME + 1).to_bytes(4, 'big'))
test_fail(lambda: _recv_json(b), contains='too large')
a.close()
test_fail(lambda: _recv_json(b), contains='')     # a closed peer is EOF, not a hang
b.close()

Checking what a client sent

A client is a separate process. The broker treats its requests as untrusted input and checks each request before it reaches the engine. The starting history of a conversation must be a list of strings. A token limit must be a positive integer when present.

test_eq(_brok_msgs({'messages': ['a', 'b']}), ['a', 'b'])
test_eq(_brok_msgs({}), [])
test_fail(lambda: _brok_msgs({'messages': [{'role': 'user'}]}), contains='invalid conversation')
test_fail(lambda: _brok_msgs({'messages': 'not a list'}), contains='invalid conversation')
test_eq(_brok_limit({'max_output_tokens': 100}), 100)
test_eq(_brok_limit({}), None)
test_fail(lambda: _brok_limit({'max_output_tokens': 0}), contains='invalid token limit')
test_fail(lambda: _brok_limit({'max_output_tokens': True}), contains='invalid token limit')
test_fail(lambda: _brok_limit({'max_output_tokens': '100'}), contains='invalid token limit')

The broker

ChatBroker(address, chat_cls, engine, model_id, **engine_kw) serves conversations at the socket path address. chat_cls is the Chat subclass of the backend. An engine is the loaded model object of the backend.

If you pass engine, the broker uses it and you release it. If you do not, start() builds an engine with chat_cls.create_engine(**engine_kw), and adds model_id=model_id when model_id is not None. close() releases an engine that the broker built. A ChatBroker is a context manager that calls start() on entry and close() on exit.

Each client connection runs in its own thread. A lock around the engine makes turns from different clients run one after another. The socket file has permissions 0600: only its owner can read and write it. Anyone who can write to the socket can use the model of the owner.

start() checks the path first. It replaces a socket file that a crashed broker left behind. It raises RuntimeError if a broker still runs at the path or if the path is not a socket. close() stops accepting connections, disconnects every client and removes the socket file.

The local backends of rishi each define a broker subclass of ChatBroker: LitertBroker, LlamaBroker and MlxBroker.

The client

BrokerChat(address, messages) opens one conversation on a running broker. messages is an optional list of earlier messages, all strings. Call the BrokerChat with a message string to get a Resp. max_output_tokens limits the length of the reply. A broker error, such as an invalid request, raises RuntimeError in the client. The broker keeps running. close() ends the conversation. Calling close() again does nothing.

Trying it

_Engine and _EngineChat stand in for a real model and a real backend. _EngineChat takes an engine and keeps its own history. It replies with the number of messages in its history, then the message. The examples below show these behaviours:

  • Two clients get separate conversations from one engine.
  • The starting history counts toward the number in the reply.
  • The broker refuses bad requests.
  • The broker replaces a stale socket.
  • The broker leaves a passed-in engine open.
class _Engine:
    "A stand-in for a loaded model. Counts how many were built and whether it was released."
    built, closed = 0, False
    def __init__(self): type(self).built += 1
    def close(self): type(self).closed = True

class _EngineChat:
    "The smallest thing `ChatBroker` will serve."
    def __init__(self, engine=None, messages=None, tools=(), **kw):
        self.engine, self.hist = engine, list(messages or [])
    @classmethod
    def create_engine(cls, **kw): return _Engine()
    def __call__(self, msg, max_output_tokens=None):
        self.hist.append(msg)
        return {'role': 'assistant', 'content': f'[{len(self.hist)}] {msg}'}
    def close(self): pass

sock = str(Path(tempfile.mkdtemp())/'broker.sock')

# a turn that never returns cannot hold `close` up, and a chat that can be cancelled is cancelled first
release = threading.Event()

class _StuckChat(_EngineChat):
    def __call__(self, msg, max_output_tokens=None): release.wait(); return {'role': 'assistant', 'content': 'late'}

class _CancelChat(_StuckChat):
    def cancel(self): release.set()

def _stuck_close(chat_cls):
    "Close a broker 0.1s after a client sent a turn that blocks, returning how long that took."
    release.clear(); _Engine.closed = False
    b = ChatBroker(sock, chat_cls).start()
    c = socket.socket(socket.AF_UNIX); c.connect(sock)
    _send_json(c, {'op': 'open'}); _recv_json(c)
    _send_json(c, {'op': 'send', 'msg': 'hi'}); time.sleep(0.2)
    t = time.time(); b.close(timeout=0.1); took = time.time() - t
    release.set(); c.close()
    return took

assert _stuck_close(_StuckChat) < 1
test_eq(_Engine.closed, False)    # the stuck turn still uses the engine, so it is left for its owner
assert _stuck_close(_CancelChat) < 1
test_eq(_Engine.closed, True)

class _TurnChat(_EngineChat):
    def __call__(self, msg, max_output_tokens=None):
        release.clear()
        turns.append(msg)
        if msg == 'first': release.wait()
        return {'role': 'assistant', 'content': msg}
    def cancel(self): release.set()

release.clear()

entered, start_turn = threading.Event(), threading.Event()

class _StartingChat(_TurnChat):
    def __call__(self, msg, max_output_tokens=None):
        entered.set(); start_turn.wait()
        release.clear()
        if not release.wait(0.3): turns.append(msg)
        return {'role': 'assistant', 'content': msg}
    def cancel(self):
        release.set(); start_turn.set()
