caps

Model inputs and outputs without loading the model.

What a model can do

Caps describes what a model can be sent and what it can send back. A modality is one of text, image, audio or video. Caps holds three tuples of modalities. Accepting images and producing images are separate abilities, so each has its own tuple.

Field Meaning
inp The modalities the model accepts
out The modalities the model returns in an ordinary reply
tools The modalities the model returns only when you give it a generation tool that the provider runs, such as the OpenAI image generation tool
source Where the answer came from

The source field has one of these values: fastllm, fallback, mmproj, config, runtime or default. The value default means that nothing knew the answer. A default Caps means the modalities are unknown. It does not mean text only. known is False for a default Caps, so a caller can tell the two cases apart.

Member Result
accepts(kind) True when kind is in inp
gen_image, gen_video True when the kind is in out or in tools
fmt() A short line for a status bar. It is empty for a text-in, text-out model, and 'modalities unknown' when known is False

source

Caps

def Caps(
    inp:tuple=('text',), out:tuple=('text',), tools:tuple=(), source:str='default'
)->None:

What a model can be sent, and what it can send back.

c = Caps(('text', 'image'), ('text',), source='fastllm')
test_eq((c.accepts('image'), c.accepts('audio')), (True, False))
test_eq((c.gen_image, c.known), (False, True))
test_eq(c.fmt(), 'in: text image')
test_eq(repr(c), 'Caps(in=text+image, out=text, fastllm)')
test_eq(Caps().known, False)
test_eq(Caps().fmt(), 'modalities unknown')
test_eq(Caps(source='fastllm').fmt(), '')
test_eq(Caps(tools=('image',), source='fastllm').gen_image, True)

Hosted models

The fastllm package ships a table of model facts. The table describes the modalities of a model in one of three ways. A fourth entry, the endpoint list, sets tools.

Table entry Caps that tbl_caps builds
Lists of input and output modalities inp and out from the lists
A supports_vision flag inp is ('text', 'image')
A mode such as image_generation out from the mode, for a model that only generates
The /v1/responses endpoint in supported_endpoints tools is ('image',)

tbl_caps(model) returns a Caps with source='fastllm'. It returns None when the table has nothing about the model. tool_modalities finds the tools value from ENDPOINT_TOOLS. A model name can carry a vendor prefix, as in openai/gpt-5.1.

c = tbl_caps('gpt-5.1')
test_eq(({'text', 'image'} <= set(c.inp), c.out, c.source), (True, ('text', 'image'), 'fastllm'))   # newer tables add inputs such as pdf
test_eq(c.tools, ('image',))              # it serves /v1/responses, so it can be told to draw
from unittest.mock import patch
with patch('fastllm.types.get_model_info', lambda m, p=None: {'mode': 'chat', 'supports_vision': True}):
    test_eq(tbl_caps('x').inp, ('text', 'image'))      # only `supports_vision` was set
test_eq({'text', 'image', 'audio', 'video'} <= set(tbl_caps('gemini-2.5-pro').inp), True)   # newer tables add pdf
test_eq(tbl_caps('gpt-image-1').out, ('image',))      # read off `mode`, not the output list
test_eq(tbl_caps('no-such-model-anywhere'), None)

The table can lack a recent model. fallback_caps(model) covers vendors whose models all read images. It checks whether the lowercased name contains a key of CAPS_FALLBACK: claude, anthropic/, sonnet, opus, haiku or fable. A match gives text and image input with source='fallback'. No match gives None.

hosted_caps(model) is the function to call for a hosted model. It tries tbl_caps, then fallback_caps. It returns an unknown Caps() when both return None.

The context window of a model is the number of tokens that the model can read at once. hosted_ctx(model) reads it from the same table. It uses max_input_tokens when that value is nonzero. Otherwise it tries max_tokens. It returns (tokens, note).

Table result tokens note
A window is listed The window ''
No window, or the lookup raises an error DFLT_CTX (128,000), or the dflt you pass Text that says the window is unknown and gives the assumed size, so you can show it to the user

Local models

A local model is named by a file path or by a Hugging Face repository id. is_path(model) returns True for a path. A name that ends in .gguf or .litertlm is a path, and so is any name that exists on disk. hub_files(repo) lists the files of a repository that are in the local Hugging Face cache. It does not use the network. It returns [] when the repository is not cached.

A GGUF model reads images only when an mmproj file comes with it. An mmproj file is a projector that converts pictures into input that the language model reads. mmproj_caps(model, model_path) looks for a .gguf file with mmproj in its name. It searches the cached repository and the folder of model_path. It also searches the folder of model when model is a path. It returns image input with source='mmproj' when it finds one. It returns None otherwise.

import tempfile

    (Path(d)/'qwen3-4b-Q4_K_M.gguf').touch()
    test_eq(mmproj_caps(None, f'{d}/qwen3-4b-Q4_K_M.gguf'), None)     # text-only
    (Path(d)/'mmproj-F16.gguf').touch()
    test_eq(mmproj_caps(None, f'{d}/qwen3-4b-Q4_K_M.gguf').inp, ('text', 'image'))

MLX and Transformers models describe themselves in a config.json file. A model with a vision or audio encoder has a key for it in that file.

read_cfg(model, model_path) loads the file from a local folder or from the Hugging Face cache. It returns {} when the file is missing or unreadable.

cfg_caps(model, model_path) returns a Caps with source='config', or None when read_cfg returns {}. Text is always an input. The table shows the keys that add an input modality.

Key in config.json Input added
vision_config, vision_tower or image_token_index image
audio_config audio
