Reading an answer out

A model often explains its reasoning before it gives the answer. To read only the answer, ask the model to put the final answer in a fenced block with the label answer. A fenced block starts with three backticks and a label on one line, and ends with three backticks on a line of their own.

extract_fence(text, tag) returns the contents of the last block that has the label tag. The default tag is answer. If the text has no such block, it returns the whole text with leading and trailing whitespace removed.

matches_(actual, expected) is the simplest grader. It returns True when actual contains expected as a substring. expected can also be a list of accepted values. The result is True when actual contains any of them.

extract_fence

def extract_fence(
    text, tag:str='answer'

The contents of the last fenced block labelled tag in text, else the whole stripped text.

test_eq(extract_fence('thinking\n```answer\n42\n```'), '42')
test_eq(extract_fence('```answer\nfirst\n```\nand\n```answer\nsecond\n```'), 'second')
test_eq(extract_fence('  just prose  '), 'just prose')      # no fence: the reply is the answer
test_eq(extract_fence('```sql\nSELECT 1\n```', 'sql'), 'SELECT 1')
test_eq(extract_fence(None), '')
test_eq(matches_('the answer is 42', 42), True)
test_eq(matches_('the answer is 42', ['41', '42']), True)   # any accepted value will do
test_eq(matches_('the answer is 42', 43), False)
test_eq(matches_(None, 1), False)

A chat to ask

_EchoChat is a test chat. It has no model. Its _oneshot returns the next item of the list replies and stores each prompt and system prompt in asked. Its _structured_call decodes the next reply as JSON.

The examples below use it to show what each method does with a given reply. The results do not depend on a real model.

class _EchoChat(Chat):
    "A chat whose `oneshot` replies from a script, for testing what the helpers do with an answer."
    _runtime, ctx_limit, token_count = 'echo', 8192, 0
    def __init__(self, model=None, *, replies=(), **kw):
        self.replies, self.asked = list(replies), []
        self._setup(model, None)
    def _oneshot(self, prompt, sp='', think=None, max_tokens=None):
        self.asked.append((prompt, sp))
        return self.replies.pop(0) if self.replies else ''
    def _structured_call(self, prompt, schema, sp):
        return json.loads(self._oneshot(prompt, sp))

register_runtime(Runtime('echo', _EchoChat, ('echo-',)))

Classifying

chat.classify(text, labels) asks the model to choose one of labels for text. It returns one item of labels, or the reply text when no label matches.

Model reply Result
Contains a label, in any case: I think this one is Ham The label as you wrote it in labels
Contains several labels The first of them in the order of labels
Contains no label The reply, in lower case, with whitespace removed from both ends

The request turns thinking off. A label is found as a substring. The label ham also matches the reply hamster.

The example below uses the labels spam and ham.

source

Chat.classify

def classify(
    text, labels, sp:str='Reply with only the single best label and nothing else.'
):

Ask the model which of labels fits text, without touching the conversation.

c = _EchoChat(replies=['spam'])
test_eq(c.classify('buy now', ['spam', 'ham']), 'spam')
assert 'spam, ham' in c.asked[0][0]
c = _EchoChat(replies=['I think this one is Ham, personally.'])
test_eq(c.classify('hello', ['spam', 'ham']), 'ham')     # matched loosely, and cased back
c = _EchoChat(replies=['no idea'])
test_eq(c.classify('hello', ['spam', 'ham']), 'no idea') # nothing matched: say so, do not guess

Structured output

chat.structured(prompt, schema) asks the model for a JSON object that matches schema. It returns an object of type schema. schema is usually a dataclass. It can also be any callable that accepts keyword arguments.

Each backend implements _structured_call(prompt, schema, sp), which returns the decoded JSON. A backend can force a tool call, or limit the output with a grammar. The base Chat raises NotImplementedError.

chat.structured builds its result with mk_obj(schema, data), where data is the decoded JSON that _structured_call returns. mk_obj rebuilds nested values from the type hints of schema. It applies the first row of this table that fits.

schema data Result
Optional[X], or a union of X and None Any mk_obj(X, data)
A union of several types, other than None Any data, unchanged
list[X] A list A list of mk_obj(X, item) for each item
tuple[X, ...] A list A tuple of mk_obj(X, item) for each item
tuple[X, Y], with fixed types A list A tuple that pairs each type with the item at the same position
Any Not a dict data, unchanged
A dataclass A dict A schema object. Nested values are rebuilt with mk_obj, using the type hints. Keys that are not init fields of the dataclass are dropped.
Another callable A dict schema(**data)

A list that does not meet a list or tuple schema is returned unchanged, as any other value that is not a dict.

from dataclasses import dataclass

@dataclass
class Addr: city: str; zip: str
@dataclass
class Person: name: str; addr: Addr

p = mk_obj(Person, {'name': 'Ada', 'addr': {'city': 'London', 'zip': 'N1'}})
test_eq(p, Person('Ada', Addr('London', 'N1')))
test_eq(type(p.addr), Addr)              # rebuilt, not left as a dict
@dataclass
class Route: stops: tuple[Addr, ...]; ends: tuple[Addr, int]

r = mk_obj(Route, {'stops': ({'city': 'Rome', 'zip': '1'},), 'ends': ({'city': 'Oslo', 'zip': '2'}, 3)})
test_eq(r, Route((Addr('Rome', '1'),), (Addr('Oslo', '2'), 3)))
r
test_eq(mk_obj(Addr, {'city': 'Rome', 'zip': '00100', 'extra': 'ignored'}), Addr('Rome', '00100'))
test_eq(mk_obj(Person, 'not a dict'), 'not a dict')
test_eq(mk_obj(dict, {'a': 1}), {'a': 1})

@dataclass
class Team: lead: Addr | None; sites: list[Addr]; pair: tuple[Addr, ...] = ()
test_eq(mk_obj(Team, {'lead': {'city': 'Rome', 'zip': '1'}, 'sites': [{'city': 'Oslo', 'zip': '2'}], 'pair': [{'city': 'Bern', 'zip': '3'}]}),
        Team(Addr('Rome', '1'), [Addr('Oslo', '2')], (Addr('Bern', '3'),)))
test_eq(mk_obj(Team, {'lead': None, 'sites': []}), Team(None, []))

Grading

chat.check(question, expected) sends question with the system prompt qa_sp_, which asks for a fenced final answer. It reads the answer with extract_fence and grades it against expected. It returns an AttrDict with the keys question, expected, answer and ok. ok is the grade.

Argument Grader Extra model request
None (default) grade_fn(answer, expected), which is matches_ by default None
grade_fn=f Your function f(answer, expected) None
llm_judge=True grades on the same chat One
judge=other_chat grades on other_chat One, to other_chat

grades(question, expected, actual) asks the model whether the answer actual is correct, given the reference answer expected. It returns True when classify selects yes from the labels yes and no. The matching rules are those of classify. A label is found as a substring of the reply, and the first label wins when the reply holds both. A reply such as no, not yes therefore grades as True.

A substring test fails when the answer is forty-two and expected is 42. A model judge compares the meaning of the two. When you pass judge, a different model grades the answer, and the model that answered does not grade itself. llm_judge and judge replace grade_fn.

Chat.grades

def grades(
    question, expected, actual
):

Ask this chat’s model whether answer actual is correct given the reference expected.

c = _EchoChat(replies=['Adding them up.\n```answer\n42\n```'])
r = c.check('what is 40+2?', 42)
test_eq((r.answer, r.ok), ('42', True))
test_eq(r.question, 'what is 40+2?')
c = _EchoChat(replies=['```answer\n41\n```'])
test_eq(c.check('what is 40+2?', 42).ok, False)
test_eq(len(c.asked), 1)                 # no second call: substring grading is free
# a judge is a second model call, and can be a different model entirely
answerer = _EchoChat(replies=['```answer\nforty-two\n```'])
judge = _EchoChat(replies=['yes'])
r = answerer.check('what is 40+2?', 42, judge=judge)
test_eq((r.answer, r.ok), ('forty-two', True))   # substring grading would have failed this
test_eq(len(judge.asked), 1)
answerer = _EchoChat(replies=['```answer\nseven\n```'])
test_eq(answerer.check('what is 40+2?', 42, judge=_EchoChat(replies=['no'])).ok, False)
c = _EchoChat(replies=['```answer\n42\n```', 'yes'])
test_eq(c.check('what is 40+2?', 42, llm_judge=True).ok, True)   # judged by itself
